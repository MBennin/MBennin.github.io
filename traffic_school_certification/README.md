# Traffic School Certification Portal v2

Copy these files into your existing `traffic_school_certification` folder.

Change this line in `verify_user/app.js`:

```js
const REQUIRED_NAME = "Robert";
```

Place the certificate image at:

```text
verify_user/certificate-placeholder.png
```

Permanently redact private information before uploading it publicly. The CSS redaction bars are only decorative.

The payment screen is simulated and never accepts or stores card information.
